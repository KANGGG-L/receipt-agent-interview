## 5. 追踪纪律（PM 自用规则）

1. **里程碑只认出口标准，不认百分比**——「阶段验收通过」比「完成 90%」可判。
2. **任务粒度 = 一天能出结果**：T-Task 均为可单日验证的切片。
3. **欠账显式化**：验收欠账/剩余任务/已知坑三清单显式记录在工单与 commit message，禁止「静默缩小范围」。
4. **每个 Sprint 收口动作固定**：checkbox 勾选 → 文档对账 → 测试基线复跑 → 交接/归档。
