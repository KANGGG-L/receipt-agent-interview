#  极简 AI 发现 (Lean AI Insights) 开发与检验方案

## 一、核心定位与防臃肿原则 (Design Principles)
- **无感融入**：零新增庞大页面，在「实时库存与价格」页面顶部嵌入单行可折叠胶囊条（40px）；
- **极简数据**：杜绝冗长 LLM 废话套话，聚焦三要素：**【涨幅 %】+【单价变化】+【量化损失 HK$ 金额】**；
- **极速行动**：提供「 查看价格走势」、「 一键复制交涉证据（支持 WhatsApp/微信）」、「 忽略本次」闭环操作。

---

## 二、详细开发方案 (Development Specification)

### 1. 后端接口与算法升级 (`demo/app/chains/review_chain.py` & `demo/app/api_admin.py`)
- **升级 `GET /api/ai-insights` 返回格式**：
  ```json
  {
    "status": "success",
    "data": {
      "has_alerts": true,
      "total_impact_amount": 680.0,
      "alert_count": 2,
      "items": [
        {
          "sku_id": 1,
          "name": "本地有机菜心",
          "vendor": "香港大埔有机农场",
          "current_price": 8.0,
          "baseline_price": 6.0,
          "change_pct": 33.3,
          "impact_amount": 500.0,
          "unit": "斤",
          "evidence_text": "大埔农场老板好，【本地有机菜心】近3笔单据单价由 $6.0 涨至 $8.0 (+33.3%)，导致累计多支出 HK$500.00，请核实一下调价明细，谢谢！"
        }
      ]
    }
  }
  ```
- **量化金额计算**：
  $$\text{impact\_amount} = \max(0, \text{current\_price} - \text{earliest\_price}) \times \text{total\_qty}$$

### 2. 前端交互与视觉实现 (`demo/static/js/main.js` & `demo/templates/index.html` & `demo/static/css/style.css`)
- **组件 1：顶部单行极简胶囊条 (`#aiLeanBanner`)**
  - 平时（无异常/已忽略）：完全隐藏；
  - 异常时：琥珀色轻量卡片，展示 ` AI 发现：本周 N 项食材价格异常上涨，预估影响成本 HK$ xxx [查看详情 (N) ▼]`。
- **组件 2：折叠展开的紧凑卡片流 (`#aiLeanCardsContainer`)**
  - 每行一张紧凑卡片（三行结构，高度 <80px）；
  - 支持一键复制文本并弹出 Toast、一键忽略平滑淡出、一键查看 SKU 价格走势弹窗。

---

## 三、检验方案 (Test & Verification Plan)

1. **接口量化测试**：
   - 验证 `impact_amount` 正确等于 `(current - baseline) * qty`；
   - 验证 `evidence_text` 格式清晰友善，适合直接发往即时通讯工具；
2. **前端交互与防臃肿断言**：
   - 验证无异常时页面无多余占用；
   - 验证点击「查看详情」流畅展开/收起；
   - 验证点击「一键复制」写入剪贴板并弹出 Toast；
   - 验证点击「忽略」后卡片隐藏且胶囊条计数即时递减。
3. **全链路回归**：
   - 保证既有 25 项业务测试 100% 通过。
