## 核心战备卡摘要

### 1. 业务破局与竞品断层（[01-业务背景与竞品剖析.md](01-业务背景与竞品剖析.md)）
- **Eats365 等 POS 巨头**：重前厅轻后厨，完全不做进货收据录入，前后端割裂。
- **Foodival**：强依赖线上标准“电子采购单（PO）”，脱离香港街市现场采买无 PO 的市井现实。
- **Air Purchase**：单点 OCR 录入工具，产生严重数据孤岛，无法实时联动 POS 销售与 BOM 菜品毛利。
- **PGM 破局点**：**【AI 多模态手写直识 + 一体化数据中台】**，打通“进-销-存-利”全生命周期。

### 2. 核心功能数字（[02-17个核心业务场景清单.md](02-17个核心业务场景清单.md)）
- **4 大业务模块**：模块 A 收据识别（8 场景）+ 模块 B 实时库存（4 场景）+ 模块 C 供应商财务（3 场景）+ 模块 D 成本分析（2 场景）= **17 个落地场景**，全面覆盖 67 个真实 API 端点。

### 3. STAR 高频面试答辩（[09-STAR金牌面试问答与胜任力矩阵.md](09-STAR金牌面试问答与胜任力矩阵.md)）
- 涵盖 **项目背景、VLM 选型深水区、三层防幻觉门禁、多租户防穿透、A/B 实验 z 检验、正则冲突缺陷排查** 等 6 大经典高频面试题。

### 4. 系统安全四层防护（[05-OCR防穿透与多租户隔离方案.md](05-OCR防穿透与多租户隔离方案.md)）
- **第 1 层：零系统上下文沙箱**（剥离用户/环境/汇总账目信息）。
- **第 2 层：租户硬隔离 RAG 检索**（Chroma metadata 强制 `tenant_id` 过滤）。
- **第 3 层：最小权限数据投影**（仅下发当前物料均价，不下发全店月度财务）。
- **第 4 层：反向渗透白名单过滤器**（Pydantic 契约阻断系统敏感信息回传）。

### 5. 落地终验成果（[04-全链路产品验收终审报告.md](04-全链路产品验收终审报告.md)）
- 阶段 0 至阶段 4 全链路产品体验综合评分 **4.92 / 5.0**（ACCEPT），并在端口 `15010` 完成全闭环活体服务验证。
