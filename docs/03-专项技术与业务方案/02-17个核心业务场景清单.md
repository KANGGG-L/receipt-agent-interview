## 二、归类逻辑（面试被问"怎么归类的"）

按**用户任务生命周期**分两条主线：
- **单据流**（A）：上传 → 识别 → 复核 → 入库 → 异常处理，覆盖收据从拍照到入账的全过程
- **管理流**（B/C/D）：库存 → 供应商/财务 → 成本，覆盖入库后的资产管理到成本洞察

辅以**角色视角**：staff 负责 A 的上传/复核，owner 负责 A 的审批与 B/C/D 全部管理动作。
