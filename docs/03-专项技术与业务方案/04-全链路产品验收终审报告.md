## 一、产品核心亮点（与传统 ERP / OCR 系统的代际差）

1. **从「黑盒工具」到「可解释可信赖伙伴」**：
   - 传统 OCR 仅吐出识别结果，报错无理由；本项目通过 **审核 Reason 自然语言输出** + **"AI 建议 vs 用户编辑" 对照面板**，让用户看清 AI 为什么标记异常，并支持单字段一键采纳（带版本乐观锁与 XSS 转义防护）。
2. **从「拍脑袋推全」到「数据驱动的 A/B 实验体系」**：
   - 建立了包含 **准确率、幻觉率、人工修正率、审核采纳率与用户信任度（滑窗）** 的完整体验指标体系；
   - 灰测分组效果对比（control vs treatment 指标差分）与 5 步漏斗转化率，让模型升级有真实业务数据支撑；
   - A/B 实验具备双比例双尾 z 检验与最小样本量硬性门禁，彻底杜绝小样本假阳性盲目推全。
3. **从「单边假对账」到「双向真实差异核对」**：
   - 突破了原系统"自证其真"的假对账闭环，支持外部月结对账单导入，自动识别 **供应商多收（vendor_only）** 与 **系统漏记（restaurant_only）**，直击餐饮财务核心痛点。
4. **从「静态表单」到「Agent 深度多步推理」**：
   - 自然语言问答 Agent（`POST /api/chat/query`）能够跨表分析供应商比价、未付账单与价格波动；
   - 复盘链不仅告警涨价，更通过 **4 步链式推理（异常检测 → 历史对比 → 行业对标 → 决策动作）** 直接生成采购谈判策略卡，实现生成式 UI 的高价值闭环。
