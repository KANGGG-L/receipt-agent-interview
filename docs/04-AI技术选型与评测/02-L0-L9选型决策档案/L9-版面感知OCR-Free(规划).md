## 选型论证

| 候选 | 范式 | 适用 | 局限 |
| :--- | :--- | :--- | :--- |
| Donut / Pix2Struct | 无 OCR 直接图→JSON | 固定版式极准 | 需训练、泛化弱 |
| LayoutLMv3 / ERNIE-Layout | 文字+坐标联合 | 固定表单 | 需大量标注样本 |
| Azure DI Custom / Textract Training | 标注后高准 | 版式稳定 | 新供应商即失效、标注成本 |

- **否决核心理由**：本产品目标 7 种形态 + 手写 + 海量长尾供应商，版式不固定。C 类模型"命中模板时极准、遇新供应商即失效"，与泛化需求根本冲突。
- 潜在价值（不否决的残留理由）：对**高频稳定版式**（如 711 热敏、某大供应商月结单）可作加速通道——但收益被标注成本 + 维护成本抵消，且 VLM 模板化（L5）已提供近似收益。
- 结论：可留作范式研究位，不投入。
