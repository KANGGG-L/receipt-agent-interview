## 选型论证

- L4 的增量：首轮通用 prompt 判 doc_form → 重试轮按形态路由专用模板（表格 A / 行语义手写 B / 月结账单 C）
- 验证命题：**模板化的价值**（R4 vs R3 的 Δ = 模板贡献）
- 落地价值（生产，非仅评测）：明确指导三套 prompt 是生产主链路的事实配置

## 结论

- **模板路由反而低于 L4 直识**：两轮调用引入更多失败点（首轮判形态错 → 模板路由错 → 契约解析失败），成功率下降 21.5pp
- 两轮模板的 token 消耗增 46%、时延增 44%——**"重抽"的边际收益不抵额外成本**
- 失败原因多为"两轮识别均无法解析为 JSON"（首轮形态判定或模板 prompt 契约问题）

## 决策

- **定论**：三模板路由**不作为评测冠军**。L4 直识（单轮）在成功率/成本/时延全面占优。
- 生产：保持通用 prompt 直识为主；模板保留为**特定形态失败时的重试选项**（而非默认两轮），与 `docs/ai/02` 的 D22 重试阶梯一致。
- 教训：模板化的价值依赖形态判定准确率；batch1 场景下判形态本身就不稳。
