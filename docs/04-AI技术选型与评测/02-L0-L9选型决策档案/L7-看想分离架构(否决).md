## 选型论证

- 架构：多模态模型只"读图"（自由文本提取，不背 JSON 约束）→ 文本 LLM 把读图结果结构化
- 验证命题：**感知与推理分离**的经济性——若文本 LLM 结构化质量不降且便宜，则省钱
- 与 L4 区别：L4 多模态一次调用直接出 JSON；L7 多模态只出文本描述，结构化交给便宜文本模型

## 结论

- **看想分离在该场景明显失败**：26.4% vs L4 的 100%
- 根因：qwen-vl-ocr-latest 是**纯 OCR 模型**（输出文字行，丢弃版式/表格语义），deepseek 结构化时大量单据无法还原表格结构 → 契约解析失败
- OCR 专用模型的"纯文本流"损失了多模态直识保留的视觉版式信息
- token 成本未必省：读图 + 结构化两段反而接近 L4 单段

## 决策

- **定论**：[ALERT]  看想分离不作为主链路。OCR 专用读图模型丢版式语义是本场景致命伤。
- 若"看想分离"要成立，读图模型必须保留版式（如 qwen3-vl-plus 而非纯 OCR 模型），但那样成本与 L4 相当、无经济性优势。
- 保留为 R7 实验结论：**本产品不需要看想分离**，多模态直识（L4）即最优。
