# 01 · 标注平台与评测工作流

> 架构：独立 FastAPI 服务（端口 15001）+ 独立 SQLite（`eval/annotation/data/eval_annotation.db`）  
> 测试集：163 张真实收据（batch1），支持 HEIC 预览转换与全层复用 GT。

---

## 一、评测与标注流程

### 1. 启动标注平台（标注 GT）
为 163 张真实收据编写标准 Expected（Ground Truth）：
```bash
# 启动标注平台（独立端口 15001）
./venv/bin/python -m eval.annotation.app --port 15001
```
- 访问：`http://127.0.0.1:15001`
- 种子管理员：`admin@eval.local` / `eval-admin-p0`
- 标注交互：左侧选图、右侧编辑（可点击“载入为起点”，复用已跑出的模型输出），保存即写入 GT。

### 2. 导出 GT 标签
```bash
./venv/bin/python -m eval.annotation.export_gt -o eval/labels_annotated.json
```

### 3. 运行指定阶梯评估（Runner）
```bash
./venv/bin/python -m eval.runner \
    --adapter r0_tesseract \
    --dataset batch1 \
    --allow-real \
    --labels eval/labels_annotated.json
```
- **无 `--labels`**：GT 回落到 `samples/expected` 草稿。
- **有 `--labels`**：标注 GT 优先，未标注项回落草稿。

---

## 二、权限与安全隔离（RBAC）

- 标注系统采用独立账号表（`eval/annotation/rbac.py`），与生产环境用户物理隔离。
- 角色定义：
  - `annotator`：查看图片、编辑标注、查阅参考模型结果。
  - `eval_admin`：具备全部权限，额外可删除 GT、重建参考库、管理标注员账号。
