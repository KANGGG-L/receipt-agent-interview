## manifest.csv 字段

| 列 | 取值 | 说明 |
| :--- | :--- | :--- |
| filename | `YYYYMMDD_供应商简称_形态.ext` | 图片文件名（YYYYMMDD = **单据日期**，非收集日期） |
| date_collected | YYYY-MM-DD | 收录进本库的日期 |
| source | 自拍 / 网络 / 客户提供 | 自拍=老板/员工实拍；客户提供=供应商或客户给予；网络=公开来源下载 |
| supplier_type | 菜档 / 肉档 / 冻品 / 粮油 / 饮品 / 批发商 / 未知 | 供应商业态；消费侧收据（如酒楼小票）填"未知" |
| doc_form | delivery_note / docket_handwritten / thermal_receipt / weight_note / correction_note / credit_note / statement | 七形态，与 `docs/01-业务流程.md` 一致；**不得填第七种以外的值**，新形态需先评审 |
| layout_type | tabular / freeform | 表格印刷 / 无表格自由手写 |
| settlement_type | cash / credit / unknown | **cash = 现结**（交货时付清，含现金/刷卡/八达通/电子支付）；**credit = 月结**（挂账，月结单结算） |
| license_or_consent | 文本 | 授权依据：供应商同意记录 / CC 许可证+来源 URL / 客户提供说明 |
| notes | 文本 | 补充：旋转/遮挡/褪色情况、隐私处理、expected 是否为草稿等 |

## expected JSON schema（与 `services/ocr_service.py` OCR 输出契约对齐）

```json
{
  "supplier_name": "供應商名稱",
  "date": "YYYY-MM-DD",
  "total_amount": 0.00,
  "items": [
    {"name": "品名", "quantity": 1.0, "unit": "斤/箱/包/隻/份/''", "unit_price": 0.00, "amount": 0.00}
  ]
}
```

录入约定：

1. `sum(items.amount)` 必须等于 `total_amount`（容差 0.01，测试会校验）。
2. 单据上的**服务费、约数差额**等附加金额，作为独立 item 录入（name 用单据原文，如"10% 服務費"），使总额自洽。
3. 单价未打印但可推算时（如数量 1 → unit_price=amount；茶 5 位共 45 → 9.0）按推算值录入；完全不可知填 0.0 并在 notes 说明。
4. 单位按单据原文录入（斤/司马斤/磅/箱/包/件/罐/隻/份）；单据无单位栏填 `""`。
5. 所有 expected 初版为 **AI 转录草稿**，notes 标注"待人工覆核"；老板/主厨人工确认后才去掉该标注，作为正式 ground truth。

## 拍摄规范（自拍样本）

- **整单入镜**：四边完整，含抬头、日期、明细、总额、印章/签名区；多联单拍主联。
- **平整**：压平或夹板，避免卷曲褶皱遮挡文字；长热敏单分段拍时保证重叠 2cm 以上并注明。
- **光线均匀**：自然光或双侧光源，避免顶光反光、阴影、闪光灯过曝；深色桌面做背景增加对比。
- **分辨率**：短边 ≥1000px；文字放大后清晰可辨（手写数字笔画可分辨）。
- **热敏纸尽快拍**：热敏字迹数月即褪色，收到当日拍；已褪色单据用侧光增强对比补拍。
- 拍完即按命名规范归档；原件按税务要求留存（7 年）。

## 合规

- **供应商同意**：自拍/客户提供的单据须供应商口头或书面同意用于系统测试（记录在 license_or_consent）。
- **隐私脱敏**：录入前模糊/裁剪与对账无关的隐私——个人电话号码、身份证号、完整卡号、八达通卡号、个人姓名地址。供应商商号电话可保留。
- **网络样本**：必须有可溯源链接与授权说明（CC 许可证 / 明确公开声明），记入 license_or_consent；版权不明的一律只记入 `sources.md` 待人工跟进，**不下载入库**。
- 样本库如随仓库外发/开源，须二次检查脱敏与许可证（CC BY-SA 样本需保留署名信息）。

交叉分布要求：

- `layout_type=freeform` ≥ 20 张（手写单多为自由排版）；
- `settlement_type=credit` ≥ 15 张（月结是主流结算方式）；
- 同一供应商尽量 ≥3 张（覆盖 Memory/few-shot 场景）；
- 含印章/手写批注（"收讫"、付款签名）≥ 5 张（payment_mark 识别用）；
- 旋转/折皱/光照不均的"困难样本" ≥ 5 张（鲁棒性）。

## 命名规范

`YYYYMMDD_供应商简称_形态.ext`

- YYYYMMDD = 单据开立日期（未知时用收集日期并在 notes 说明）；
- 供应商简称 ≤8 字符，繁体原文优先，不含空格与 `/ \ : * ? " < > |`；
- 形态 = doc_form 值；ext ∈ jpg/jpeg/png/webp；
- 同供应商同日同形态冲突时追加 `_2`、`_3`；
- 示例：`20260803_陳記菜檔_docket_handwritten.jpg`、`20260715_嘉頓_delivery_note.png`。
