## 二、决定性活体验证（最权威）

通过运行中的服务（`127.0.0.1:15010`），对一张**同时含手机号 + 18 位身份证**的真实单据（id=1）实测：

| 字段 | 明文（不带参数） | 脱敏（`?desensitized=true`） |
|------|------------------|-------------------------------|
| `supplier_name` | `供应商 张明 13812345678 身份证 440123199001011234` | `供应商 张明 138****5678 身份证 440123********1234` |
| `raw_llm` | （明文） | `供应商:张明, 电话:138****5678, 身份证:440123********1234` |
| `payment_mark` | （空） | （空） |

**判定**：
- 手机号 `13812345678`(11位) → `138****5678`(11位) [PASS]  长度一致、前3后4保留
- 身份证 `440123199001011234`(18位) → `440123********1234`(18位) [PASS]  长度一致、前6后4保留、中间生日段完整遮罩
- 关键语义验证：身份证**未被手机号正则误吃生日段**（未出现 `440123199****11234` 这种错误形态）[PASS] 
- `raw_llm` 字段同步脱敏，含双字段时均正确 [PASS] 

**dev 自承的"残留语义风险"在活体上未复现**——身份证正则 `\b\d{17}[0-9Xx]\b` 的词边界优先匹配整串，手机号正则无匹配机会。
