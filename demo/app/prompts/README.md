# 全项目 LLM 提示词工程化资产库与评测中心（Prompt Hub & Benchmarks）

> 适用系统：香港餐饮进货收据识别、库存治理与供应链决策 Agent
> 架构原则：模块解耦、语义化版本（SemVer）、严格防穿透、多维评测闭环（Evaluation-Driven）

## 一、全景业务场景与组件映射

站在整个餐饮供应链与收据治理项目的全局视角，LLM 被解耦并应用在以下 **6 大核心业务场景** 中：

```text
                           【香港餐饮进货与库存治理 LLM 场景全景】
                                         │
    ┌─────────────────┬──────────────────┼──────────────────┬─────────────────┐
    ▼                 ▼                  ▼                  ▼                 ▼
【1. extract 视觉提取】 【2. parse 规范化】 【3. audit 交叉审核】 【4. review 采购复盘】 【5. query 智能问答】 【6. memory 知识提炼】
```

1. **`extract` (VLM OCR 视觉提取)**：负责从繁体手写、街市 NCR 复写纸单、热敏机打单中纯视觉提取结构化明细。
2. **`parse` (文本规范化清洗)**：负责繁简食材对齐（如「西蘭花」->「西兰花」）、港式单位标准化（司马斤 600g、磅、打、板）。
3. **`audit` (交叉审核 Agent)**：对照原图复核提取结果，发现单价异动、数量错配，生成人类可读的审核 Reason 并防御间接注入。
4. **`review` (采购复盘与谈判策略)**：基于 30 天库存加权成本，完成 4 步多步推理（异常检测 → 历史对比 → 行业对标 → 决策动作）并生成式输出采购谈判卡片。
5. **`query` (问 AI - 对话式查询 Agent)**：支持用户自然语言查询跨表比价、供应商未付赊单与价格走势，自带越权与注入拦截器。
6. **`memory` (供应商记忆提炼 RAG Distiller)**：人工 Approve 确认后，自动提炼该商户版式特征与食材别称，沉淀进 Chroma 向量库。

## 三、API 与代码调用指引

### 1. 代码内部动态拉取
```python
from app.prompts import get_prompt, get_metrics

# 获取默认生产版本 Prompt
prompt_text = get_prompt("extract")

# 指定拉取香港手写优化版
hk_prompt = get_prompt("extract", version="v1_1_0_hk")

# 获取该版本的基准评测数据
metrics = get_metrics("extract", version="v1_1_0_hk")
```
