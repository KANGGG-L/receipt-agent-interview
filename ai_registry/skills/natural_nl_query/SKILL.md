# Natural NL Query Skill (自然语言查账技能)

## 技能概述
接收店主关于进货量、库存结余、供应商未结账款及食材采购均价的口语化提问，自动转换为安全的只读聚合 SQL 并组织答复。

## 操作步骤
1. **意图与时间实体抽取**：解析时间范围（如“上个月”、“本周”）、品类与供应商；
2. **生成租户隔离 SQL**：强制携带 `WHERE tenant_id = :tenant_id` 与 `SELECT` 权限；
3. **组织自然语言答复**：用精炼香港本地餐饮口吻输出统计数值与趋势分析。
