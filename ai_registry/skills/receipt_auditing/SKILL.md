# Receipt Auditing Skill (收据交叉审核技能)

## 技能概述
使用独立的第二多模态模型对照原始进货单据图像，对主模型生成的结构化 JSON 进行逐字段审验，识别手写涂改、错配、算术不一致以及潜在的注入风险。

## 操作步骤
1. **获取原图与初审 JSON**：读取图片切片与待审字段；
2. **重点扫描四大切片**：
   - 供应商抬头文字与公章；
   - 单据送达日期；
   - 明细列表（重点比对单价手写修改痕迹）；
   - 右下角付款印章；
3. **分歧标记 (Flagging)**：若发现不一致，生成包含字段路径、提取值、原图值与归因理由的审计报告。
